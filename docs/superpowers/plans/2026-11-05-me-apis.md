# Nhóm API "của tôi" (`/api/v2/me/*`) và app nhân viên — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nhân viên dùng app `/nv/*` và `/nv-may-tinh` trên dữ liệu thật: xem hôm nay, chấm công, xem công tháng, nộp/huỷ đơn, xem thu nhập (chính thức hoặc tạm tính), sửa hồ sơ đọc-chỉ, tự chấm KPI.

**Architecture:** Module mới `src/modules/me/` (controller mỏng, mọi route `@Authenticated()`), danh tính luôn là `req.user` (`username` + `uuid`), gọi lại service sẵn có của attendance, requests, payroll, employees. Logic gộp mới là hàm thuần trong `src/modules/me/domain/`. FE: `web/src/builders/api/staff-phone.ts` dựng `HomeView`, `AttendanceView`, `DayDetail`, `RequestsView`, `RequestDetail`, `IncomeView`, `ProfileView` từ phản hồi; `services/staff-phone.ts` và `services/staff-desktop.ts` có nhánh máy chủ thật.

**Tech Stack:** NestJS 10 + Kysely, `node:test` + tsx; Vue 3, Playwright.

**Trạng thái (2026-11-05):** đã thực thi native theo goal của người dùng. Task 1–8 xong (`test/v2/me-domain.test.ts`, `me-controller.test.ts`, `fe-staff-phone-builders.test.ts`); Ruling: `/nv-may-tinh` chưa dựng lại trên `/me`, chế độ `api` chuyển sang `/nv/hom-nay`. Task 9 (Playwright với BE thật) chưa chạy: chưa có Postgres.

**Spec:** `docs/superpowers/specs/2026-11-05-missing-apis-design.md` mục 3.1 (và spec nền `2026-11-05-fe-be-auth-foundation-design.md`).

## Global Constraints

- Mọi route `/api/v2/me/*` mang `@Authenticated()`; test "mặc định đóng" (`test/v2/auth-access.test.ts`) thêm từng handler vào bảng.
- Không route nào đọc `employeeId`, `username`, `reviewerId` từ body/query/path; trường lạ bị bỏ qua.
- Nhận diện nhân sự: timesheet, punch, lịch dùng `req.user.uuid`; đơn từ dùng `listRequests({ employeeId: req.user.username })` (service tự gộp username + uuid); phiếu lương dùng `username`.
- Lỗi nghiệp vụ trả `400` với `code` riêng; lỗi không lường trước đi `500` (không bọc `err.message` thành 400 như controller cũ).
- Không chạy `npm run typecheck`, `npm run format:check`. Xác minh: `npm test` (gốc), `npm --prefix web run test:ui`, `npm --prefix web run build` + kiểm `dist` không có dữ liệu giả.
- Thư mục chưa phải git repo: chưa có bước commit cho tới khi có repo gốc.

## Review Focus

1. Nhân viên gửi `employeeId`/`username` của người khác trong body hoặc query → bị bỏ qua, dữ liệu vẫn của chính mình (Task 1, test `ignores foreign ids`).
2. Huỷ đơn của người khác hoặc đơn không còn `PENDING` → 404 / 409, không đổi gì (Task 3).
3. Tháng chưa có công, chưa có phiếu, thiếu cấu hình bậc lương → `GET /me/income` trả `state: 'unavailable'` với lý do, không 500 (Task 6).
4. Chấm công lúc nửa đêm theo giờ Việt Nam (UTC+7) → ngày công đúng theo giờ VN (Task 4, test `vn midnight`).
5. Tài khoản bị khoá giữa chừng → mọi route `/me/*` trả 401 ngay lần gọi kế tiếp (đã có ở guard; Task 1 thêm một ca hồi quy).
