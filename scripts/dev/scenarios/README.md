# DB kịch bản cả năm (01/2026 → 02/2027)
- Dựng: `node scripts/dev/scenarios/generate.cjs` → `out/scenario-year.sqlite`, `out/events.jsonl`, `out/cases.json` (thử nhanh 3 người × 2 tháng: `--smoke`; chỉ vài người: `--only u1,u2`); mỗi lần dựng xoá luôn bản làm việc `out/scenario-year.run.sqlite` và giờ đã lưu `out/clock.json`.
- Xem: `node scripts/dev/scenarios/server.cjs` → http://127.0.0.1:3300 (đồng hồ 01/03/2027 09:30, chỉ tiến; `--fresh` chép lại bản dựng; nhân vật ở `/__scenario`, vào thẳng `/__scenario/as/<tài khoản>`); lệnh điều khiển `POST /__scenario/clock {"local":"YYYY-MM-DDTHH:mm"}` và `POST /__scenario/user {"username":"…"}` (cũng nhận `/__sandbox/clock`, `/__sandbox/user`) cần header `x-scenario-control: 1` (hoặc `x-sandbox-control: 1`) và Origin cùng địa chỉ.
- Đối chiếu: `node scripts/dev/scenarios/verify.cjs` → `out/report.md`, `out/report.json` (OK / DIFF / PENDING-RULE / CHECK, mục "Phép năm 01–02/2027", mã danh mục gộp hoặc không dựng trong DB).
- Mọi file sinh ra nằm trong `out/` (không đưa vào git).
